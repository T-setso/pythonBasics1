# Python Basics 1

This repository contains beginner Python exercises and practice programs created while learning Python programming fundamentals.

## Project Description

The project focuses on basic Python concepts such as:

- User input
- Variables
- Data types
- String formatting
- Arithmetic operations
- Printing output
- Simple calculations

The file `Operation_Inpute_types.py` demonstrates how to:

1. Capture information from users
2. Store data in variables
3. Display formatted output
4. Perform calculations using integer conversion

## Technologies Used

- Python 3
- GitHub
- Pycharm

## Current Files

### Operation_Inpute_types.py
A beginner Python program that:
- Captures names, ages, and heights of two users
- Displays their information
- Calculates the combined height of both users

## Learning Goals

The purpose of this repository is to:
- Practice Python syntax
- Understand user input handling
- Improve problem-solving skills
- Build a strong programming foundation
